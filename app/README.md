# 自動レポーティング — Instagram 運用管理・月次レポート（デモ）

クライアント提案用のインタラクティブデモです。ブラウザだけで動作し、データは localStorage（レポートファイルは IndexedDB）に保存されます。

## 起動

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に静的ファイルを出力（HashRouter のため任意の静的ホスティングで動作）
```

Node.js 18 以上。基準日は **2026年10月23日** に固定しています（実行日に関係なくデータの整合性を保つため）。

## デモの範囲と本番開発の範囲

**このデモで実際に動くもの**：全画面の操作と状態遷移、.pptx の生成とダウンロード（PowerPoint 上で編集できるネイティブグラフ）、修正版 .pptx の読み込みと自動チェック（所見の文字数・スライド枚数）、KPI 目標の CSV 取り込み、承認ワークフロー、監査ログ。

**本番開発で実装するもの**：Instagram Graph API 連携（日次取得・トークン更新）、認証とサーバー側の権限チェック、DB・ファイル保管、月次集計の自動確定バッチ、承認依頼などの通知、監査ログの改ざん防止保管。

**対象外**：AI による所見の自動生成、提出時のメール送信（記録のみ）。

## 構成

```
src/
  domain/     業務ロジック（型・ダミーデータ・集計・自動チェック・権限・CSV 解析）※ React に依存しない
  services/   PowerPoint 生成（pptxgenjs）・アップロードファイルの検査（JSZip）・ファイル保存（IndexedDB）
  store/      状態管理（zustand + localStorage）。すべての変更操作は監査ログに記録
  ui/         ボタン・入力・ダイアログ・トースト等の共通部品
  layout/     サイドバー・ヘッダー・ページ遷移
  pages/      各画面
```

React 18 / TypeScript / Vite / Tailwind CSS / Motion for React / Recharts / Radix UI / pptxgenjs。

## ワイヤーフレームからの変更点

- ダミー企業名を実在しそうな架空企業に置き換え、ワイヤー内の不整合（「株式会社／合同会社チャーリー」、アカウント名の揺れ、10/18 の曜日など）を解消
- 指示書に従い「ホーム」は作らず、ログイン後はクライアント一覧を表示。「運用業務」メニューは定義がないため省略
- KPI はワイヤーの「保存数・プロフィールのリンクタップ」に、指示書の「インプレッション・エンゲージメント」を加えた 6 指標
